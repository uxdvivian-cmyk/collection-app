# 建立免費的 Google Sheets API 金鑰（一次性，約 5 分鐘）

用途：讓收藏帳本直接讀取朋友的書單（Google 試算表），按一下就同步。金鑰只存在你手機的瀏覽器裡，唯讀。

前提：試算表的分享設定是「知道連結的人 → 檢視者」。

1. 開啟 <https://console.cloud.google.com/>，用你的 Google 帳號登入。
2. 上方專案選單 →「新增專案」，名稱隨意（例如「收藏帳本」）→ 建立。
3. 左上選單 →「API 和服務」→「程式庫」，搜尋 **Google Sheets API** →「啟用」。
4. 「API 和服務」→「憑證」→「建立憑證」→「API 金鑰」，複製產生的金鑰（`AIza…`）。
5. 在該金鑰按「編輯」做限制（建議，避免被別人盜用）：
   - 應用程式限制：選「網站」，新增你的網址，例如 `https://<你的帳號>.github.io/*`
   - API 限制：選「限制金鑰」，只勾 **Google Sheets API**。
6. 打開收藏帳本 →「設定」→「Google 試算表同步」，貼上試算表網址與金鑰。

之後在「書」→「匯入 Excel」→「從 Google 試算表同步」，會顯示預覽，確認後才寫入。
Sheets API 的讀取額度對個人使用綽綽有餘，不需要綁定付款方式。
